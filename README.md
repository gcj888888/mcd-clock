# 麦门时钟 mcd-clock

到饭点不知道吃啥？问一句"现在吃啥"——它先看现在几点，再查麦当劳实时在售菜单和能领的券，按早餐/午餐/下午茶/晚餐/深夜档给推荐，连券后价和营养信息都备好。

它还是一个**店长经营助手**：每天录一次销量，它帮你做日/周/节假日对比、备货建议，周三生意差就提议设个会员日——**店长点头才执行**。

## 目标用户

- **选择困难症**：每天到饭点纠结吃什么的人
- **时间敏感型**：想赶早餐尾班车、下午茶、深夜档的人
- **精打细算型**：希望点餐前把能领的券自动领掉的人
- **个性化需求型**：几个人吃、多少预算、要低卡还是过瘾，一次说清
- **门店店长**：需要销量记录、对比分析、备货和促销建议的经营者

## 安装方法

1. 申请麦当劳 MCP Token：打开 open.mcd.cn/mcp，手机号登录 → 控制台 → 激活 → 复制 Token
2. 在你的 MCP 客户端（推荐 WorkBuddy）中配置 mcd-mcp：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer ${MCD_MCP_TOKEN}"
      }
    }
  }
}
```

（把 `${MCD_MCP_TOKEN}` 替换为你的真实 Token；仓库中不包含任何真实凭证）

3. 将本仓库 `mcd-clock/SKILL.md` 放入 WorkBuddy 技能目录
4. 店长模式需要本机有 Python 3（分析脚本只用标准库，无需安装第三方包）
5. 对话中输入"现在吃啥"（食客）或"录销量/看分析/促销建议"（店长）即可触发

### 店长模式

> 店长：录一下今天的销量，麦辣鸡腿汉堡 35 份、薯条 50 份、可乐 40 份、麦辣鸡翅 22 份
> 麦门时钟：已记入 data/sales_1950640.csv（2026-10-24）。
>
> 店长：看下这周情况，周三好像不太行
> 麦门时钟：（运行分析脚本后）周三连续 3 周低于整体均值约 38%……
> 建议把周三设为固定会员日（如"周三会员日第二份半价"）。**是否同意上线该活动？**
>
> 店长：同意
> 麦门时钟：已核对当月官方活动日历无撞车，活动记入台账 data/promotions.csv（状态：已批准）。

（店长模式演示数据为虚构样本 data/sales_sample.csv，仅用于展示分析效果）

## 能力边界（如实说明）

- 麦当劳 MCP 提供：时间、活动日历、附近门店、实时菜单、餐品详情、营养数据、优惠券、价格试算。
- 麦当劳 MCP **不提供**门店历史销量。店长模式的销量数据由店长每日录入（POS 导出或手工汇总），存本地 CSV，由分析脚本处理。
- 语音输入取决于客户端支持；Skill 对文字与语音转文字输入同等处理。
