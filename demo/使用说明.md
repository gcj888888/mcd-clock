# 麦门时钟 · 使用说明

> 本文件同时作为 WaytoAGI 1024「用餐」赛道要求的「使用说明」提交材料。
> 配套材料：demo/demo_transcript.md（2026-10-24 真实执行实录）。

## 这是什么

「麦门时钟」是一个基于麦当劳 MCP 的 WorkBuddy Skill（AI 技能包），解决两类问题：

1. **食客侧**：到饭点不知道吃啥——它先读真实当前时间，查附近门店实时在售菜单、当月活动和可领优惠券，按你的人数/预算/口味/饮食偏好，给出 3 个算好券后价的推荐方案，每个都附推荐理由和热量营养信息。
2. **店长侧**：每天录一次销量，它自动做环比/同期对比、星期分布、爆款和高峰时段分析，给出备货建议；发现某个星期几连续冷淡就提议设会员日，节日来临前 7 天提前预警——**所有促销必须店长点头才执行**。

## 怎么用（食客）

1. 按 README 装好 mcd-mcp 连接器和本 Skill
2. 对话里直接说：**"现在吃啥"**（可以带上"两个人、爱吃辣、人均 35、想低卡"）
3. 它会问你位置，报城市+地标（如"北京 中关村"）
4. 收到 3 个方案后，说"方案 2"或"就要第一个"即完成选择；说"领券"它会帮你把能领的券领掉

## 怎么用（店长）

1. 说 **"录销量"** 并粘贴当日销量（POS 导出或口语报数都行，如"麦辣鸡腿汉堡 35 份、薯条 50 份"）
2. 说 **"看分析"**：输出日报（环比/同期）、星期分布、Top 餐品、高峰时段、备货建议
3. 说 **"促销建议"**：给出节日前 7 天预警和淡季日会员日候选；回复"同意"才记入台账（还会先核对官方活动日历防撞车），"不同意"则记录原因

## 已知边界（如实说明）

- 麦当劳 MCP 不提供门店历史销量，店长模式的销量数据由店长每日录入，存本地 CSV
- 语音输入取决于客户端支持，Skill 对语音转文字与文字输入同等处理
- 新品（如龙焰鸡腿堡）暂无官方营养数据时，Skill 会如实说明，不用估算冒充官方数据
